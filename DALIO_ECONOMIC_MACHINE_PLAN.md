## Part 1: Dalio's Complete Economic Framework

### 1.1 The Fundamental Building Block: Transactions

> "An economy is simply the sum of all transactions."

A **transaction** occurs when a buyer exchanges **money** or **credit** with a seller for goods, services, or financial assets.

```
Total Spending = Money + Credit
```

**Key insight**: Credit is the most important and least understood part of the economy. In the US, total credit is ~$50 trillion while actual money is only ~$3 trillion.

### 1.2 The Circular Flow

> "One person's spending is another person's income."

This creates the self-reinforcing nature of the economy:
- When you spend more → someone else earns more
- When someone earns more → lenders are more willing to lend
- More lending → more spending → more income → more lending...

This positive feedback loop is why we have **cycles**.

### 1.3 Credit and Debt Duality

> "As soon as credit is created, it immediately turns into debt."

- **Debt is an asset** to the lender
- **Debt is a liability** to the borrower
- When the borrower repays principal + interest, the asset and liability disappear

### 1.4 Creditworthiness

Creditworthiness has two components:

1. **Ability to repay** = Income relative to debt (debt service coverage)
2. **Collateral** = Assets that can be seized if borrower defaults

When income rises → creditworthiness rises → more borrowing possible

### 1.5 Good Credit vs. Bad Credit

| Good Credit | Bad Credit |
|-------------|------------|
| Finances productive investment | Finances excess consumption |
| Generates income to repay debt | Cannot be paid back |
| Efficiently allocates resources | Creates unsustainable bubbles |
| Example: Business equipment loan | Example: Vacation on credit card |

## Part 2: The Three Driving Forces

### 2.1 Force #1: Productivity Growth

- The **most important** factor in the long run
- Grows steadily at ~2-3% annually
- Doesn't fluctuate much (not a driver of swings)
- Determines long-term living standards
- The line that everything else oscillates around

**Productivity Rule**: Don't have income rise faster than productivity, or you'll become uncompetitive.

### 2.2 Force #2: Short-Term Debt Cycle (5-8 years)

The "business cycle" driven by credit expansion and contraction.

#### Expansion Phase:
1. Credit is easily available
2. Spending increases (spending = money + credit)
3. Incomes rise (one person's spending = another's income)
4. Asset prices rise
5. People feel wealthy, borrow more
6. Inflation increases
7. Central bank raises interest rates

#### Peak:
- Inflation too high
- Central bank tightens significantly
- Credit becomes expensive

#### Contraction Phase (Recession):
1. Borrowing decreases (high rates)
2. Spending decreases
3. Incomes fall
4. Asset prices fall
5. People feel poor, borrow less
6. Inflation falls/deflation
7. Central bank lowers rates

#### Trough:
- Rates low enough to stimulate borrowing again
- Cycle restarts

**Key insight**: Each cycle ends with more growth AND more debt than the previous cycle. People have an inclination to borrow and spend more rather than pay back debt - it's human nature.

### 2.3 Force #3: Long-Term Debt Cycle (75-100 years)

The "supercycle" that builds over decades.

#### The Buildup (decades):
- Over many short-term cycles, debts rise faster than incomes
- Debt burdens increase but are manageable
- Asset prices rise, making people feel wealthy
- Lenders keep lending (collateral values high)
- This can continue for 50-75 years

#### The Peak:
- Debt service costs exceed income growth
- Interest rates hit 0% (zero lower bound)
- Central bank's main tool becomes ineffective
- "Pushing on a string" - can't stimulate more borrowing

#### The Deleveraging:
- Debt burden must come down relative to income
- This is a **different animal** than a recession
- Cannot be solved by lowering interest rates
- Typically takes 10+ years ("lost decade")

## Part 3: The Deleveraging Process

### 3.1 The Four Levers

When debt burden becomes unsustainable, policymakers have four tools:

| Lever | Effect | Nature |
|-------|--------|--------|
| **1. Austerity** | Cut spending | Deflationary, depressing |
| **2. Debt Defaults/Restructuring** | Reduce debt burden | Deflationary, depressing |
| **3. Wealth Transfers** | Tax wealthy, redistribute | Political, redistributive |
| **4. Money Printing** | Monetize debt | Inflationary, stimulating |

### 3.2 The Austerity Trap

> "Policy makers typically try austerity first because it's the obvious thing to do. This is a big mistake."

Why austerity alone fails:
- One person's spending = another's income
- Cutting spending cuts incomes
- Lower incomes make debt burden WORSE (debt/income ratio rises)
- Deflationary spiral ensues

### 3.3 Beautiful Deleveraging vs. Ugly Deleveraging

#### Ugly Deleveraging (Depression):
- Dominated by austerity and defaults
- Not enough money printing to offset deflation
- Real economy contracts severely
- Social unrest increases
- Can last a decade or more
- Example: 1930s Great Depression (initially)

#### Beautiful Deleveraging:
- Balanced use of all four levers
- Money printing offsets deflationary forces
- Debt burdens fall while economy grows
- Inflation stays manageable
- Nominal growth > nominal interest rates
- Example: US post-2008 (after QE began)

**The key**: Balance deflationary forces (austerity, defaults) with inflationary forces (money printing) so they offset each other.

### 3.4 Types of Debt Crises

#### Deflationary Depression:
- Debt denominated in **local currency**
- Can be monetized by central bank
- No currency crisis
- Asset prices fall, deflation
- Example: US 1930s, US 2008

#### Inflationary Depression:
- Debt denominated in **foreign currency**
- Cannot be monetized (would devalue currency)
- Capital flight, currency collapse
- High inflation despite economic contraction
- Example: Germany 1920s, Argentina, Turkey

**Key indicator**: 75% correlation between foreign debt and inflation in crises

## Part 4: Central Bank and Policy

### 4.1 Monetary Policy Types

#### MP1: Interest Rate Policy
- Primary tool in normal times
- Lower rates → stimulate borrowing
- Raise rates → cool inflation
- **Limitation**: Zero lower bound

#### MP2: Quantitative Easing (QE)
- Used when MP1 exhausted (rates at 0%)
- Central bank prints money to buy assets
- Pushes investors into riskier assets
- **Limitation**: Benefits asset holders (wealth inequality)

#### MP3: Fiscal-Monetary Coordination
- Central bank funds government spending directly
- Government spends newly printed money
- Gets money into real economy
- **Risk**: Requires political coordination

### 4.2 The Zero Lower Bound Problem

When rates hit 0%:
- Traditional monetary policy stops working
- "All the reserve country central banks' interest rate stimulation tools won't work"
- Must rely on QE and fiscal policy
- Only happened twice in past century (1930s, 2008)

### 4.3 Inflation Dynamics

```
Inflation = (Total Spending Growth) - (Productivity Growth)
         = (Money Growth + Credit Growth) - (Real Output Growth)
```

If money printing offsets credit contraction → no net inflation

## Part 5: Dalio's Rules of Thumb

### The Three Golden Rules

1. **Don't have debt rise faster than income**
   - Debt burdens will eventually crush you
   - Monitor debt/income ratios carefully

2. **Don't have income rise faster than productivity**
   - You'll become uncompetitive
   - Wages must reflect real output

3. **Do all you can to raise productivity**
   - In the long run, this is what matters most
   - Investment in technology, education, efficiency

#### 1. Transaction System
```typescript
class TransactionSystem {
  /**
   * Processes all transactions each tick.
   * Implements: Spending = Money + Credit
   * Implements: One person's spending = another's income
   */

  processTransaction(tx: Transaction, state: WorldState): void {
    // Debit buyer
    const buyerAccount = this.getAccount(tx.buyer);
    buyerAccount.cash -= tx.moneyAmount;

    // Credit creates debt
    if (tx.creditAmount > 0) {
      this.createDebt(tx);
    }

    // Credit seller (their income!)
    const sellerAccount = this.getAccount(tx.seller);
    sellerAccount.income += tx.moneyAmount + tx.creditAmount;
  }
}
```

```typescript
class CreditSystem {
  /**
   * Manages credit creation, repayment, and defaults.
   * Tracks good vs bad credit.
   * Monitors creditworthiness.
   */

  assessCreditworthiness(borrower: Entity): Creditworthiness {
    const income = this.getIncome(borrower);
    const debtService = this.getDebtService(borrower);
    const collateral = this.getCollateralValue(borrower);
    const totalDebt = this.getTotalDebt(borrower);

    return {
      abilityToRepay: income / debtService,
      collateralCoverage: collateral / totalDebt,
      overallScore: this.calculateScore(income, debtService, collateral, totalDebt),
      maxBorrowingCapacity: this.calculateMaxBorrowing(income, collateral)
    };
  }

  isGoodCredit(loan: CreditAgreement): boolean {
    // Good credit finances productive investment
    // that generates income to repay
    return loan.purpose === 'productive' &&
           loan.expectedReturnRate > loan.interestRate;
  }
}
```

```typescript
class ProductivitySystem {
  /**
   * Models steady productivity growth (~2-3% annually).
   * The baseline that everything oscillates around.
   */

  private baseProductivity: number;
  private annualGrowthRate: Percentage = 0.025;  // 2.5%

  update(state: WorldState, monthsElapsed: number): number {
    const years = monthsElapsed / 12;
    return this.baseProductivity * Math.pow(1 + this.annualGrowthRate, years);
  }

  getProductivityTrend(fromMonth: number, toMonth: number): number[] {
    // Returns the steady productivity line for charting
    return range(fromMonth, toMonth).map(m => this.update(null, m));
  }
}
```

#### 4. Short-Term Debt Cycle System
```typescript
class ShortTermDebtCycleSystem {
  /**
   * Models the 5-8 year business cycle.
   * Driven by credit expansion and contraction.
   * Controlled by central bank interest rates.
   */

  private cyclePeriodMonths: number = 72;  // 6 years average
  private currentPosition: number = 0;

  update(state: WorldState, delta: TimeStep): void {
    // Update cycle position
    this.currentPosition = (this.currentPosition + delta) % this.cyclePeriodMonths;

    // Determine phase
    const phase = this.determinePhase();

    // Adjust credit conditions based on phase
    this.adjustCreditConditions(state, phase);

    // Central bank responds to inflation
    this.centralBankResponse(state);
  }

  private determinePhase(): CyclePhase {
    const position = this.currentPosition / this.cyclePeriodMonths;

    if (position < 0.4) return 'expansion';
    if (position < 0.5) return 'peak';
    if (position < 0.9) return 'contraction';
    return 'trough';
  }

  private centralBankResponse(state: WorldState): void {
    const inflation = state.inflation;
    const targetInflation = 0.02;  // 2%

    if (inflation > targetInflation + 0.01) {
      // Raise rates to cool inflation
      state.centralBank.policyRate += 0.0025;  // 25 bps
    } else if (inflation < targetInflation - 0.01) {
      // Lower rates to stimulate
      if (state.centralBank.policyRate > 0) {
        state.centralBank.policyRate -= 0.0025;
      }
    }
  }
}
```

#### 5. Long-Term Debt Cycle System
```typescript
class LongTermDebtCycleSystem {
  /**
   * Models the 75-100 year debt supercycle.
   * Tracks debt accumulation over decades.
   * Triggers and manages deleveraging.
   */

  private debtToGDPHistory: number[] = [];

  update(state: WorldState, delta: TimeStep): void {
    // Track debt accumulation
    this.debtToGDPHistory.push(state.debtToGDPRatio);

    // Check if deleveraging should trigger
    if (this.shouldTriggerDeleveraging(state)) {
      this.startDeleveraging(state);
    }

    // If deleveraging, manage the process
    if (state.isDeleveraging) {
      this.manageDeleveraging(state);
    }
  }

  private shouldTriggerDeleveraging(state: WorldState): boolean {
    // Dalio's conditions:
    // 1. Debt burden too high (debt service > income growth)
    // 2. Interest rates at zero (can't lower more)
    // 3. Credit growth stalling despite low rates

    const debtBurdenTooHigh = state.debtServiceToIncome > 0.4;
    const atZeroLowerBound = state.centralBank.atZeroLowerBound;
    const creditGrowthStalling = state.creditGrowth < 0.02;

    return debtBurdenTooHigh && atZeroLowerBound && creditGrowthStalling;
  }

  private manageDeleveraging(state: WorldState): void {
    // Apply the four levers
    const levers = state.deleveragingLevers;

    // Calculate deflationary vs inflationary forces
    const deflationaryForce = levers.austerity + levers.defaults;
    const inflationaryForce = levers.moneyPrinting;

    // Beautiful deleveraging = balanced forces
    const balance = inflationaryForce - deflationaryForce;

    if (Math.abs(balance) < 0.1) {
      state.deleveragingType = 'beautiful';
    } else {
      state.deleveragingType = 'ugly';
    }
  }
}
```

#### 6. Deleveraging System
```typescript
class DeleveragingSystem {
  /**
   * Implements Dalio's four levers for deleveraging.
   * Manages beautiful vs ugly deleveraging.
   */

  applyAusterity(state: WorldState, intensity: Percentage): void {
    // Cut government spending
    state.government.spending *= (1 - intensity * 0.1);

    // But this cuts income too!
    // One person's spending = another's income
    state.nominalGDP *= (1 - intensity * 0.05);

    // Deflationary
    state.inflation -= intensity * 0.01;
  }

  applyDebtRestructuring(state: WorldState, intensity: Percentage): void {
    // Write down debts
    const writedownRate = intensity * 0.1;

    for (const loan of state.allLoans) {
      if (loan.status === 'active' && Math.random() < writedownRate) {
        // Principal reduction
        loan.remainingPrincipal *= 0.7;

        // Lender takes loss (their asset shrinks!)
        const lender = this.getEntity(loan.lender);
        lender.assets -= loan.remainingPrincipal * 0.3;
      }
    }

    // Deflationary but reduces debt burden
    state.debtToGDPRatio *= (1 - writedownRate);
  }

  applyWealthTransfer(state: WorldState, intensity: Percentage): void {
    // Increase taxes on wealthy
    const additionalTax = intensity * 0.05;

    for (const household of state.wealthyHouseholds) {
      const tax = household.financialAssets * additionalTax;
      household.financialAssets -= tax;
      state.government.taxRevenue += tax;
    }

    // Redistribute via transfer payments
    state.government.transferPayments += state.government.taxRevenue * 0.5;
  }

  applyMoneyPrinting(state: WorldState, intensity: Percentage): void {
    // Central bank creates money
    const newMoney = state.nominalGDP * intensity * 0.05;
    state.centralBank.balanceSheet += newMoney;
    state.centralBank.qeActive = true;
    state.centralBank.qePurchases += newMoney;

    // Buy government bonds (monetize debt)
    state.government.debt -= newMoney * 0.5;  // Effectively

    // Inflationary (if not offset by credit contraction)
    if (state.creditGrowth < 0) {
      // Printing money offsets credit contraction
      // Net effect on inflation is neutral
    } else {
      state.inflation += intensity * 0.01;
    }
  }

  calculateBeautifulDeleveraging(state: WorldState): DeleveragingMix {
    /**
     * Beautiful deleveraging requires:
     * - Debt/income ratios declining
     * - Economic activity positive
     * - Inflation manageable
     *
     * This means balancing:
     * - Enough austerity/defaults to reduce debt
     * - Enough printing to offset deflation
     * - Nominal growth > nominal interest rates
     */

    const targetInflation = 0.02;
    const targetGrowth = 0.02;

    // Start with equal mix
    let mix = {
      austerity: 0.25,
      defaults: 0.25,
      wealthTransfer: 0.1,
      moneyPrinting: 0.4
    };

    // Adjust based on current conditions
    if (state.inflation < targetInflation) {
      // Need more printing
      mix.moneyPrinting += 0.1;
      mix.austerity -= 0.1;
    }

    if (state.realGDPGrowth < 0) {
      // Need more stimulus
      mix.moneyPrinting += 0.1;
      mix.defaults -= 0.05;
      mix.austerity -= 0.05;
    }

    return this.normalize(mix);
  }
}
```

#### 7. Central Bank System
```typescript
class CentralBankSystem {
  /**
   * Implements MP1, MP2, MP3.
   * Manages zero lower bound.
   * Controls credit conditions.
   */

  update(state: WorldState): void {
    // Determine which monetary policy to use
    if (!state.centralBank.atZeroLowerBound) {
      this.applyMP1(state);  // Interest rate policy
    } else if (state.creditGrowth < 0) {
      this.applyMP2(state);  // QE
    } else if (state.isDeleveraging) {
      this.applyMP3(state);  // Fiscal coordination
    }
  }

  private applyMP1(state: WorldState): void {
    // Taylor Rule-like interest rate setting
    const inflation = state.inflation;
    const outputGap = (state.realGDP - state.potentialGDP) / state.potentialGDP;
    const naturalRate = 0.02;  // 2%
    const inflationTarget = 0.02;

    const targetRate = naturalRate
      + 1.5 * (inflation - inflationTarget)
      + 0.5 * outputGap;

    // Gradually move towards target
    const adjustment = (targetRate - state.centralBank.policyRate) * 0.25;
    state.centralBank.policyRate += adjustment;

    // Zero lower bound
    state.centralBank.policyRate = Math.max(0, state.centralBank.policyRate);
    state.centralBank.atZeroLowerBound = state.centralBank.policyRate < 0.0025;
  }

  private applyMP2(state: WorldState): void {
    // Quantitative Easing
    // Buy assets to push investors into riskier assets
    // Lower long-term rates

    state.centralBank.qeActive = true;

    // Size QE based on how far below target we are
    const shortfall = state.inflationTarget - state.inflation;
    const qeAmount = shortfall * state.nominalGDP * 0.1;

    state.centralBank.qePurchases += qeAmount;
    state.centralBank.balanceSheet += qeAmount;

    // Effect on long-term rates
    state.marketRates.longTerm -= qeAmount / state.nominalGDP * 0.1;
    state.marketRates.longTerm = Math.max(0, state.marketRates.longTerm);
  }

  private applyMP3(state: WorldState): void {
    // Fiscal-Monetary Coordination
    // Central bank directly funds government spending

    state.centralBank.fiscalMonetization = true;

    // Print money for government to spend
    const monetization = state.government.deficit;
    state.centralBank.balanceSheet += monetization;

    // Money goes into real economy (not just assets)
    // More effective at generating real activity
  }
}
```

#### 8. Inflation System
```typescript
class InflationSystem {
  /**
   * Implements: Inflation = Spending Growth - Productivity Growth
   */

  update(state: WorldState, previousState: WorldState): void {
    const spendingGrowth = (state.totalSpending - previousState.totalSpending)
      / previousState.totalSpending;

    const productivityGrowth = (state.productivityLevel - previousState.productivityLevel)
      / previousState.productivityLevel;

    // Core inflation from spending vs output
    state.inflation = spendingGrowth - productivityGrowth;

    // Asset price inflation (can diverge from consumer inflation)
    const assetDemandGrowth = state.creditGrowth;  // Credit often goes to assets
    state.assetPriceInflation = assetDemandGrowth * 2;  // More volatile
  }
}
```

```typescript
// /src/utils/dalioFormulas.ts

/**
 * Dalio's fundamental equation
 */
export function totalSpending(money: Money, credit: Money): Money {
  return money + credit;
}

/**
 * The circular flow
 */
export function incomeFromSpending(
  totalEconomySpending: Money,
  entityMarketShare: Percentage
): Money {
  return totalEconomySpending * entityMarketShare;
}

/**
 * Creditworthiness calculation
 */
export function creditworthiness(
  income: Money,
  debtService: Money,
  collateral: Money,
  debt: Money
): Percentage {
  const abilityToRepay = Math.min(1, income / (debtService * 2));
  const collateralCoverage = Math.min(1, collateral / debt);
  return (abilityToRepay * 0.6) + (collateralCoverage * 0.4);
}

/**
 * Debt burden
 */
export function debtBurden(
  annualDebtService: Money,
  annualIncome: Money
): Percentage {
  return annualDebtService / annualIncome;
}

/**
 * Should trigger deleveraging?
 */
export function shouldDeleveraging(
  debtBurden: Percentage,
  interestRate: Percentage,
  creditGrowth: Percentage,
  incomeGrowth: Percentage
): boolean {
  return (
    debtBurden > 0.35 &&  // Debt service > 35% of income
    interestRate < 0.01 &&  // Rates near zero
    creditGrowth < incomeGrowth  // Credit growth stalling
  );
}

/**
 * Inflation from Dalio's framework
 */
export function inflation(
  spendingGrowth: Percentage,
  productivityGrowth: Percentage
): Percentage {
  return spendingGrowth - productivityGrowth;
}

/**
 * Real GDP vs Nominal GDP
 */
export function realGDP(nominalGDP: Money, priceLevel: number): Money {
  return nominalGDP / priceLevel;
}

/**
 * Is this "good" credit?
 */
export function isGoodCredit(
  expectedReturn: Percentage,
  interestRate: Percentage,
  purpose: 'productive' | 'consumptive'
): boolean {
  return purpose === 'productive' && expectedReturn > interestRate;
}

/**
 * Beautiful deleveraging check
 * Nominal growth must exceed nominal interest rates
 * While debt/income declines
 */
export function isBeautifulDeleveraging(
  nominalGrowth: Percentage,
  nominalInterestRate: Percentage,
  debtToIncomeChange: Percentage,
  inflation: Percentage
): boolean {
  return (
    nominalGrowth > nominalInterestRate &&
    debtToIncomeChange < 0 &&  // Debt burden declining
    inflation > 0 && inflation < 0.05  // Manageable inflation
  );
}

/**
 * Central bank rate using Taylor-like rule
 */
export function taylorRate(
  naturalRate: Percentage,
  inflation: Percentage,
  inflationTarget: Percentage,
  outputGap: Percentage
): Percentage {
  const rate = naturalRate
    + 1.5 * (inflation - inflationTarget)
    + 0.5 * outputGap;
  return Math.max(0, rate);  // Zero lower bound
}
```

- [x] Zero lower bound
